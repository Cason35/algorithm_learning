# 学习文档稳定 ID 迁移

- 日期：2026-10-30
- 状态：已验证
- 变更类型：内容结构

## 背景与目标

平台仍通过“科目 ID + 仓库相对路径”临时推导部分文档 ID。文件移动或重命名后该 ID 会变化，因此需要把当前推导值显式写入文档 front matter，保持既有网址和提交引用不变。

## 范围

- 包含：平台已发现且尚未声明 `id` 的课程、作答单、进度与路线 Markdown。
- 不包含：算法实现、测试、课程正文、任务、学习状态和未被平台清单发现的文件。

## 现状分析

迁移前平台报告 19 份旧文档使用路径派生 ID；这些文档均没有 front matter。

## 方案与取舍

为每份目标文档原样保留正文，只在文件开头加入 `id` front matter。`id` 使用迁移前平台生成的 UUIDv5 十六进制值，确保现有 URL 与证据引用不失效。

## 实际修改

- `day1` 至 `day16` 的 16 份 `class_schedule.md`、`day16/worksheet.md`、`PROGRESS.md`、`README.md`：各新增三行稳定 ID front matter，正文保持不变。

## 学习流程与数据影响

不推进学习任务，不修改代码作业、测试、进度或历史证据；只把已有隐式身份固定为显式身份。

- [x] 注册表检查：所有平台文档 ID 唯一，本仓旧文档 ID 警告清零。

## 风险与回滚

风险是误写 ID 导致旧链接失效。回滚时仅移除本次新增的三行 front matter；正文不参与回滚。
