# Day 16：广度优先搜索（BFS）

## 今天目标

Day 15 的深度优先搜索会沿着一条分支走到底；广度优先搜索（Breadth-First Search，BFS）则按距离一层一层向外扩散。

今天要掌握：

1. 使用队列保存“已经发现、等待处理”的节点。
2. 使用当前队列长度划分树的层级。
3. 理解 BFS 为什么能在无权图中找到最短步数。
4. 在网格中使用方向数组和 `visited` 防止重复访问。

## 1. BFS 的直觉

想象一滴墨水落进清水中，它会先染到距离最近的位置，再逐渐向外扩散：

```text
距离 0：起点
距离 1：起点一步能到的位置
距离 2：起点两步能到的位置
...
```

BFS 使用先进先出的队列。先发现的节点先处理，因此距离起点更近的节点一定先于更远的节点出队。

## 2. 树的层序遍历

考虑下面的树：

```text
        3
       / \
      9   20
         /  \
        15   7
```

对应输入：

```js
const root = buildTree([3, 9, 20, null, null, 15, 7]);
```

按层输出：

```js
[[3], [9, 20], [15, 7]]
```

处理每一层前，先保存当时的队列长度：

```js
const levelSize = queue.length - head;
```

接下来只处理这 `levelSize` 个节点。期间新加入的子节点属于下一层，不能混进当前层。

## 3. 队列在 JavaScript 中的写法

直接反复调用数组的 `shift()` 会移动剩余元素，单次可能是 `O(n)`。本课程继续使用队首指针：

```js
const queue = [root];
let head = 0;

while (head < queue.length) {
  const node = queue[head];
  head += 1;

  // 处理 node，并把它的邻居 push 到队尾
}
```

这样每个元素只会入队、出队各一次，总时间保持线性。

## 4. 二叉树右视图

如果站在树的右侧，每一层只能看到最右边的节点。

示例输入：

```js
const root = buildTree([3, 9, 20, null, null, 15, 7]);
rightSideView(root);
```

树形结构：

```text
        3        -> 看到 3
       / \
      9   20     -> 看到 20
         /  \
        15   7   -> 看到 7
```

最终输出：

```js
[3, 20, 7]
```

层序遍历时，每层最后一个出队的节点就是这一层的右视图节点。

## 5. 二叉树最小深度

最小深度是从根节点到最近叶子节点经过的节点数。叶子节点必须同时满足：

```js
node.left === null && node.right === null
```

仍使用上面的树：

```js
const root = buildTree([3, 9, 20, null, null, 15, 7]);
minDepth(root);
```

最终输出：

```js
2
```

因为 `3 -> 9` 已经到达叶子，只经过 2 个节点。BFS 第一次遇到叶子时可以立即返回，因为后面节点的深度不会更小。

特别注意：只有一个子节点的节点不是叶子。对于下面的树：

```text
    1
   /
  2
 /
3
```

最小深度是 `3`，不能把缺失的右子树当成一条长度为 `0` 的叶子路径。

## 6. 网格中的最短路

网格也可以看成图：每个可通行格子是一个节点，上下左右相邻格子之间有一条边。

本题约定：

- `0` 表示可以通行。
- `1` 表示障碍。
- 从左上角 `[0, 0]` 出发，到右下角 `[rows - 1, columns - 1]`。
- 每次只能上下左右移动一格。
- 返回最少移动次数；无法到达返回 `-1`。

示例输入：

```js
const grid = [
  [0, 0, 1, 0],
  [1, 0, 0, 0],
  [1, 1, 1, 0],
];

shortestPathInGrid(grid);
```

一条最短路径是：

```text
[0,0] -> [0,1] -> [1,1] -> [1,2] -> [1,3] -> [2,3]
```

最终输出：

```js
5
```

这里计算的是“移动次数”，所以路径包含 6 个格子，但答案是 5。

## 7. 为什么入队时就要标记访问

网格中的同一个位置可能从多个方向到达。如果等到出队时才标记，它可能在此前被重复加入队列很多次。

正确时机是：

```text
发现合法邻居 -> 立即标记 visited -> 加入队列
```

这样每个格子最多入队一次，时间和空间复杂度都是 `O(rows × columns)`。
