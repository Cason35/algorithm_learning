## 1. 二叉树是什么

二叉树的每个节点最多有两个子节点，分别叫 `left` 和 `right`：

```text
        1          <- 根节点
       / \
      2   3
     / \
    4   5          <- 3、4、5 都是叶子节点
```

- `1` 是根节点。
- `2` 和 `3` 是 `1` 的子节点。
- 以 `2` 为根的部分也是一棵树，叫 `2` 的子树。
- 没有子节点的节点叫叶子节点。
- 这棵树的最大深度是 `3`。

节点类通常写成：

```js
class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}
```

## 3. 树递归的统一模板

处理树时可以先建立一个承诺：

```text
traverse(node) 会正确处理以 node 为根的整棵子树。
```

通用结构是：

```js
function traverse(node) {
  if (node === null) {
    return;
  }

  // 处理当前节点、左子树、右子树
  // 三者的先后顺序决定遍历类型
}
```

空节点是最小子问题，也是最常见的终止条件。

## 4. 前序遍历：根、左、右

前序遍历先处理当前节点，再处理左右子树：

```text
根 -> 左 -> 右
```

对于示例树：

```text
        1
       / \
      2   3
     / \
    4   5
```

最终输出：

```js
[1, 2, 4, 5, 3]
```

前序遍历适合先处理父节点，再处理子节点的场景，例如复制树结构。

## 5. 中序遍历：左、根、右

中序遍历先处理左子树，再处理当前节点，最后处理右子树：

```text
左 -> 根 -> 右
```

同一棵树最终输出：

```js
[4, 2, 5, 1, 3]
```

以后学习二叉搜索树时，中序遍历会得到升序结果。

## 6. 后序遍历：左、右、根

后序遍历先处理两个子树，最后处理当前节点：

```text
左 -> 右 -> 根
```

同一棵树最终输出：

```js
[4, 5, 2, 3, 1]
```

后序遍历适合必须先知道子树答案、再计算当前节点答案的场景，例如计算目录大小或树的高度。

## 7. 计算最大深度

一棵非空树的最大深度等于：

```text
1 + max(左子树深度, 右子树深度)
```

空树深度为 `0`。

示例输入：

```js
const root = buildTree([1, 2, 3, 4, 5]);
maxDepth(root);
```

最终输出：

```js
3
```

因为最长路径是 `1 -> 2 -> 4` 或 `1 -> 2 -> 5`，共有 3 个节点。

## 8. 复杂度怎么分析

四道题都要访问每个节点一次。设节点总数为 `n`、树高为 `h`：

- 时间复杂度：`O(n)`。
- 递归调用栈：`O(h)`。
- 最坏情况下树退化成链表，`h = n`，调用栈是 `O(n)`。
- 平衡二叉树中，`h` 约为 `log n`。

三个遍历函数还会返回包含全部节点值的数组，这部分结果空间是 `O(n)`；通常分析额外空间时会把必需的返回结果单独说明。

### 可以继续优化的点

- 三个遍历函数中的 `result` 引用没有重新赋值，可以声明为 `const`，更准确地表达变量意图。
- 完成实现后可以删除遗留的 `TODO` 前缀，避免以后搜索未完成任务时产生干扰。
- 当前辅助函数短而清楚，这是树递归很适合的写法。相比把左右子树结果反复用展开运算符合并，向同一个 `result` 数组 `push` 不会重复复制累计结果，复杂度更稳定。

### 今天真正学到的东西

三种深度优先遍历的递归骨架完全相同，差别只在“什么时候处理当前节点”：递归之前是前序，左右之间是中序，递归之后是后序。最大深度则展示了另一种树递归模式：不维护外部结果，而是让每棵子树向父节点返回一个答案。
