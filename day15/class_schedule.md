## 1. 二叉树是什么

二叉树的每个节点最多有两个子节点，分别叫 `left` 和 `right`：

```text
        1          <- 根节点
       / \
      2   3
     / \
    4   5          <- 3、4、5 都是叶子节点
```

- `1` 是根节点。
- `2` 和 `3` 是 `1` 的子节点。
- 以 `2` 为根的部分也是一棵树，叫 `2` 的子树。
- 没有子节点的节点叫叶子节点。
- 这棵树的最大深度是 `3`。

节点类通常写成：

```js
class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}
```

## 2. 作业中的树如何输入

`day15/work.js` 已提供 `buildTree(values)`，它会把层序数组转换为树。`null` 表示该位置没有节点。

例如输入：

```js
const root = buildTree([1, 2, 3, 4, 5]);
```

得到：

```text
        1
       / \
      2   3
     / \
    4   5
```

另一个例子：

```js
const root = buildTree([1, null, 2, 3]);
```

得到：

```text
    1
     \
      2
     /
    3
```

注意：数组只是方便创建测试数据；真正传给作业函数的是根节点 `root`，不是数组。

## 3. 树递归的统一模板

处理树时可以先建立一个承诺：

```text
traverse(node) 会正确处理以 node 为根的整棵子树。
```

通用结构是：

```js
function traverse(node) {
  if (node === null) {
    return;
  }

  // 处理当前节点、左子树、右子树
  // 三者的先后顺序决定遍历类型
}
```

空节点是最小子问题，也是最常见的终止条件。

## 4. 前序遍历：根、左、右

前序遍历先处理当前节点，再处理左右子树：

```text
根 -> 左 -> 右
```

对于示例树：

```text
        1
       / \
      2   3
     / \
    4   5
```

最终输出：

```js
[1, 2, 4, 5, 3]
```

前序遍历适合先处理父节点，再处理子节点的场景，例如复制树结构。

## 5. 中序遍历：左、根、右

中序遍历先处理左子树，再处理当前节点，最后处理右子树：

```text
左 -> 根 -> 右
```

同一棵树最终输出：

```js
[4, 2, 5, 1, 3]
```

以后学习二叉搜索树时，中序遍历会得到升序结果。

## 6. 后序遍历：左、右、根

后序遍历先处理两个子树，最后处理当前节点：

```text
左 -> 右 -> 根
```

同一棵树最终输出：

```js
[4, 5, 2, 3, 1]
```

后序遍历适合必须先知道子树答案、再计算当前节点答案的场景，例如计算目录大小或树的高度。

## 7. 计算最大深度

一棵非空树的最大深度等于：

```text
1 + max(左子树深度, 右子树深度)
```

空树深度为 `0`。

示例输入：

```js
const root = buildTree([1, 2, 3, 4, 5]);
maxDepth(root);
```

最终输出：

```js
3
```

因为最长路径是 `1 -> 2 -> 4` 或 `1 -> 2 -> 5`，共有 3 个节点。

## 8. 复杂度怎么分析

四道题都要访问每个节点一次。设节点总数为 `n`、树高为 `h`：

- 时间复杂度：`O(n)`。
- 递归调用栈：`O(h)`。
- 最坏情况下树退化成链表，`h = n`，调用栈是 `O(n)`。
- 平衡二叉树中，`h` 约为 `log n`。

三个遍历函数还会返回包含全部节点值的数组，这部分结果空间是 `O(n)`；通常分析额外空间时会把必需的返回结果单独说明。
